# Bilyard Club Online

Railway-ready Flask web app: 5 billiard tables + 3 tennis tables.

Features:
- Real-time 1-second timers based on epoch timestamps
- 5 billiard + 3 tennis tables
- Product menu and sales
- Daily/weekly/monthly reports
- Admin-protected settings
- Login password and admin password
- Background (oboy) image upload
- SQLite database created automatically

Railway starts the app with Gunicorn from the Procfile.
